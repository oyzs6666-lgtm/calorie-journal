# 今日热量柱状图版

这是一个手机端单页热量柱状图。统计页底部直接输入热量，保存时按当前选中日期和手机当前时间生成柱子，不再记录食物名称，也不显示记录列表。

## 时间分区

- 0:00–8:00 压缩为一格
- 8:00–21:00 每小时一格
- 21:00–24:00 压缩为一格

## 热量分区与颜色

- 0–1000 kcal 每 100 kcal 一格
- 1000 kcal 以上压缩为顶部一格
- 柱子按照精确热量在绿色到深红色之间连续取色
- 超过 1000 kcal 使用更深的红色

同一时间格内有多条记录时会合并成一根柱。轻触柱子可查看时间段和总热量；长按柱子可修改热量、时间或删除。如果同一柱内有多条记录，会先让用户选择其中一条。

网页数据使用独立的浏览器本地存储，不会与原“饱腹感折线图版”的记录混合。
