# 今日热量柱状图版

这是从“饱腹感折线图版”独立复制出的新版本。记录页只记录食物名称、热量和系统时间；统计页按时间区间汇总当天热量并绘制柱状图。

## 时间分区

- 0:00–8:00 压缩为一格
- 8:00–21:00 每小时一格
- 21:00–24:00 压缩为一格

## 热量分区与颜色

- 0–1000 kcal 每 100 kcal 一格
- 1000 kcal 以上压缩为顶部一格
- 柱子从低热量蓝色开始，依次经过原饱腹度 1–10 的固定色阶
- 超过 1000 kcal 使用更深的红色

同一时间格内有多条记录时会合并成一根柱。轻触柱子可选中并查看时间段、食物与总热量。

网页数据使用独立的浏览器本地存储，不会与原“饱腹感折线图版”的记录混合。
