# 今日热量柱状图版

这是一个手机端单页热量柱状图。统计页底部直接输入热量，保存时按当前选中日期和手机当前时间生成柱子，不再记录食物名称，也不显示记录列表。

## 时间分区

- 0:00–8:00 压缩为一格
- 8:00–21:00 每小时一格
- 21:00–24:00 压缩为一格

## 热量分区与颜色

- 0–1000 kcal 每 100 kcal 一格
- 1000 kcal 以上压缩为顶部一格
- 柱子按照精确热量在绿色到深红色之间连续取色
- 超过 1000 kcal 使用更深的红色

同一时间格内有多条记录时会合并成一根柱。轻触柱子可查看时间段和总热量；长按柱子可修改热量、时间或删除。如果同一柱内有多条记录，会先让用户选择其中一条。

热量输入框旁提供悬浮计算器，支持四则运算、括号、小数点和退格；括号会写入上方算式并参与整段运算。普通运算和千焦换算的结果都会四舍五入为整数，再自动回填热量输入框。计算器底部还可根据“每100g千焦数”和“重量”换算 kcal，并把整数结果加入当前算式。

关闭计算器后再次打开会保留尚未记录的原算式；保存热量后清空本次算式，新增柱子不会自动进入选中状态。

图表顶部居中显示所选日期的热量总和数字（不附加单位），直接使用坐标轴上方的原有留白，不改变图表白框或坐标框尺寸。

网页数据使用独立的浏览器本地存储，不会与原“饱腹感折线图版”的记录混合。
